# Create a project
**Expo** — это фреймворк *React Native*, который облегчает разработку приложений для *Android* и *iOS*,
также это открытый исходный код с активным сообществом на *GitHub* и *Discord*.

### Чтобы создать новый проект, выполните следующую команду: 
*npx create-expo-app@latest*

### Чтобы просмотреть полный список и выбрать интерактивно, запустите с помощью 
*create-expo-app--example* Опция и Нет имени: *npx create-expo-app@latest --example*

### Чтобы создать известный пример напрямую, передайте его имя: 
*npx create-expo-app@latest --example with-widgets*

Новый проект включает файлы контекста проекта, которые агенты ИИ читают: 8AGENTS.md*, *CLAUDE.md* и *.claude/settings.json.* **Claude Code** и **Codex также** имеют официальный плагин для *Expo*.
Используя одну команду, вы можете установить *Expo Skills* и зарегистрировать сервер *Expo Model Context Protocol (MCP):        claude plugin install expo@claude-plugins-official*
Затем пройдите внутрь сессии *Claude Code* и войдите в свой аккаунт *Expo./mcp*

Для **Cursor** и других агентов устанавливайте 
**Expo Skills** и **Expo MCP Server** отдельно. В обзоре AI-агентов и обзор выставки охватываются настройки для каждого агента.

   # Set up your environment
**Expo CLI** — создан для того, чтобы помочь вам быстрее двигаться на этапе разработки приложения. Например, ваше первое взаимодействие с **Expo CLI** — это запуск сервера разработки с помощью команды: **.npx expo start**

   ## EAS CLI 
используется для входа в ваш аккаунт **Expo** и компиляции приложения с помощью различных сервисов **EAS**. 
#### Вы также можете использовать этот инструмент, чтобы:
Опубликуйте своё приложение в магазинах приложений
Создайте разработку, превью или продакшн для вашего приложения
Управляйте учетными данными вашего приложения
Создайте **ad hoc** профиль для устройства **iOS**

## Нужно установить его глобально на вашем локальном компьютере, выполнив команду: 
###### npm install --global eas-cli
Эта команда выполняет проверки и анализ кодовой базы вашего проекта на предмет распространённых проблем с конфигурацией приложения : **npx expo-doctor**
Также можно использовать для отображения информации об использовании
###### npx expo-doctor --help

  ## Expo Tools для VS Code
**Expo Tools** — это расширение **VS Code**, которое улучшает опыт разработки при работе с конфигурационными файлами приложений. 
Он предоставляет такие функции, как автозаполнение и intellisense для файлов, таких как конфигурация приложений, конфигурация **EAS**, конфигурация **хранилища** и конфигурации **модуля Expo**.

  ## Каталог React Native
Любая библиотека, совместимая с *React Native*, работает в проекте **Expo**, когда вы используете *build* для создания проекта.
**reactnative.directory** — это поисковая база данных библиотек *React Native*. Если библиотека, которую вы ищете, не включена в **Expo SDK**, используйте каталог, чтобы найти совместимую библиотеку для вашего проекта.

3. Сделайте первое изменение
Откройте файл *src/app/index.tsx* в редакторе кода и внесите изменения.

# Приложение
Содержит навигацию приложения, которая основана на файлах. Структура файлов каталога *src/app* определяет навигацию приложения.

В приложении есть два маршрута, определяемых двумя файлами: *src/app/index.tsx* и *src/app/explore.tsx.* Файл верстки в *src/app/_layout.tsx* настраивает навигатор вкладок с помощью платформенного компонента **AppTabs**.



## Сбросьте проект
Вы можете убрать стандартный код и начать новый проект.
Выполните следующую команду для сброса проекта: *npm run reset-project*
Эта команда переместит существующие файлы в приложении в *app-example*, затем создаёт новую папку приложения с новым файлом *index.tsx*.

 ## Передача параметров между экранами
#### Данные передаются через *params*.

#### Переход вперёд: *navigation.navigate('RouteName')* — добавляет экран сверху.
#### Возврат назад: *navigation.goBack()* или кнопка «Назад» — убирает верхний экран.
#### Полный возврат к первому экрану: *navigation.popToTop().*
